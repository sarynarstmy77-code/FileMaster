# 📁 Smart File Organizer

A simple and useful file organizer built with **C#**.

## 🚀 About the Project

Smart File Organizer is a C# console application that helps you organize your files automatically based on their file extensions.

Instead of keeping all your files in one folder, this program helps you sort them into separate categories, making your folders cleaner and easier to navigate.

## ✨ Features

* 🖼️ **Images:** JPG, JPEG, PNG, GIF, BMP, WEBP
* 📄 **Documents:** PDF, DOC, DOCX, TXT, XLS, XLSX, PPT, PPTX
* 🎬 **Videos:** MP4, MKV, AVI, MOV, WMV
* 🎵 **Music:** MP3, WAV, FLAC, AAC, OGG
* 📦 **Archives:** ZIP, RAR, 7Z, TAR, GZ

## 🛠️ Built With

* C#
* .NET
* System.IO

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio.
3. Build and run the application.
4. Follow the instructions displayed in the console.
5. Choose an option and provide the folder path when requested.

## 🎯 Project Goal

The goal of this project is to make file management easier while practicing C# programming, working with file extensions, and using the `System.IO` library.
